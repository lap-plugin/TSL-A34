LAP TSL-A34 is a two-channel JFET compressor / limiter built as a component-level circuit model. The plugin does not run a "compressor algorithm":
the whole audio board (input followers, gain stage, the JFET-controlled stage, the precision rectifier, the attack / release network, the RATIO divider
and the balanced output driver) is solved as a circuit in real time, component by component
