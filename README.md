LAP TSL-A34 is a two-channel JFET compressor / limiter built as a component-level circuit model. The plugin does not run a "compressor algorithm":
the whole audio board (input followers, gain stage, the JFET-controlled stage, the precision rectifier, the attack / release network, the RATIO divider
and the balanced output driver) is solved as a circuit in real time, component by component

The TSL-A34 compressor-limiter is designed in a two-channel configuration. The input signal (e.g., from a mixing console or equalizer) is fed into the input connectors INPUT 1 and 2. When using the device for signal limiting, it is necessary to set a short attack time constant (ATTACK) and a long release time constant (RELEASE). Set the GAIN and OUTPUT controls to zero, and the RATIO control to a compression ratio of 10 : 1.The output signal level can be adjusted using the LEVEL controls in the range of 0 dB to 6 dB. The BYPASS switch serves to deactivate the compressor-limiter. The LIMIT indicator is used to monitor the limited output voltage. The GAIN indicator signals overloading of the input amplifier. If the GAIN indicator lights up during an acoustic signal, it is necessary to reduce the input voltage level using the GAIN control.
